Cascading Style Sheets (CSS) Fundamentals

Read through this lesson text to understand how CSS transforms static HTML into visually compelling web pages. Keep these concepts in mind as you move on to the Guided Notes!

01

Introduction to Cascading Style Sheets (CSS)

Cascading Style Sheets, commonly known as CSS, are used to format and design the layout of web pages. While HTML structures the actual content of a page (like text, images, and headers), CSS controls the visual presentation (or appearance) such as colors, fonts, layouts, and spacing.

When web designers want to make a site visually appealing and well-structured, CSS provides the tools to modify how HTML elements are rendered on a screen.

02

Standard 1: Three Ways to Apply CSS to a Website

Inline Styles

An inline style is used to apply a unique style directly to a single HTML element. Designers write the CSS code inside the HTML tag using the style attribute. Because inline styles only affect one specific element on a page, they are generally inefficient for styling an entire website, but they are useful for quick, single-element style adjustments.

<h1 style="color: blue;">Hello World</h1>

Internal Stylesheets

An internal stylesheet is used to style a single web page by placing CSS rules directly inside the HTML document. These style rules are placed within the <style> tags located in the <head> section of the HTML file. While internal styles keep code organized for one individual page, they cannot easily share styling rules across multiple pages on a site.

External Stylesheets (Best Coding Practice)

Using an external stylesheet is considered the best coding practice for web development. In this method, all CSS rules are stored in a separate file with a .css file extension. This external file is then connected to HTML pages using the <link> tag in the head section, allowing a designer to change the look of an entire website by editing just one single file.

03

Standard 2: Essential CSS Syntax & Rules

Every CSS style rule consists of two main parts: a selector and a declaration block. The selector specifies which HTML element you want to style, such as a paragraph, heading, or image. Inside the curly braces, each declaration contains a property and a value separated by a colon (:). Every individual declaration must end with a semicolon (;) to separate it from the next rule.

// Anatomy of a CSS Rule
h1 { color: blue; }
h1: Selector
color: Property
blue: Value
; Semicolon

Reflection Answer Exemplars & Rubric

Q1. External Stylesheets rationale:

Model Answer: External stylesheets separate design from structure. Changing a single `.css` file updates the entire website instantly rather than editing every HTML page individually. Inline styles are only useful for quick, single-element visual tests or quick fixes.

Q2. Box Model Padding vs Margin:

Model Answer: To create space inside the box around the text, adjust padding. To push the two boxes apart from one another, adjust margin.
